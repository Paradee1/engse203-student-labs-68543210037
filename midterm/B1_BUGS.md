# B1 · บันทึกการแก้บั๊ก (กรอกให้ครบทั้ง 6 จุด)

> แต่ละบั๊กให้เขียน 4 อย่าง: ไฟล์ · บรรทัด · สาเหตุ (ทำไมทำงานผิด) · แก้อย่างไร
> เขียนด้วยคำของตัวเอง — จุดนี้จะถูกถามใน oral

## บั๊กที่ 1 — อาการ: Console เตือนสีเหลืองเรื่องรายการ
- ไฟล์/บรรทัด: RequestList / 9
- สาเหตุ: มีการใช้ฟังก์ชัน .map() แต่ไม่ได้ใส่ prop key ให้กับคอมโพเนนต์ <RequestCard/> ทำให้ React ไม่สามารถระบุและติดตามการเปลี่ยนแปลงของแต่ละ Element ใน DOM ได้อย่างถูกต้อง
- แก้อย่างไร: เติม key={request.id} ลงใน <RequestCard/>

## บั๊กที่ 2 — อาการ: ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็น
- ไฟล์/บรรทัด: DashboardPage.jsx / 47
- สาเหตุ: status เป็น completed แต่มี completed อยู่แล้วในบรรทัด 51 ทำให้ตัวเลข รอดำเนินการ ในแผงไม่ตรงกับความเป็นจริง
- แก้อย่างไร: แก้จาก pending: requests.filter((request) => request.status === 'completed').length, เป็น pending: requests.filter((request) => request.status === 'pending').length,

## บั๊กที่ 3 — อาการ: กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่
- ไฟล์/บรรทัด: DashboardPage.jsx / 55
- สาเหตุ: request.status ใช้ !== ทำให้เมื่อกดกรองจะขึ้นรายการที่ไม่ตรงกับที่ต้องการดู
- แก้อย่างไร: แก้จากใช้ !== เป็น === เพื่อให้ขึ้นตามที่เราต้องการ

## บั๊กที่ 4 — อาการ: เปลี่ยน URL จาก REQ-001 เป็น REQ-002 แล้วข้อมูลไม่เปลี่ยน
- ไฟล์/บรรทัด: RequestDetailPage / 28
- สาเหตุ: ใน useEffect ใส่แค่ reloadKey ทำให้เมื่อผู้ใช้เปลี่ยน URL จาก REQ-001 เป็น REQ-002 ตัว React จะไม่รัน Effect ใหม่เพื่อดึงข้อมูลของ ID ใหม่มาแสดงผล ข้อมูลหน้าจอจึงยังค้างเป็นรายการเดิม
- แก้อย่างไร: เพิ่ม requestId เข้าไปใน useEffect เป็น [requestId, reloadKey]
## บั๊กที่ 5 — อาการ: กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย
- ไฟล์/บรรทัด: DashboardPage.jsx / 65
- สาเหตุ: setRequests(requests); ส่ง Array เดิมเข้าไป React จะมองว่า State ไม่เปลี่ยน ทำให้ต้องรีเฟรชถึงจะหาย
- แก้อย่างไร: แก้จาก setRequests(requests); เป็น setRequests(nextRequests);


## บั๊กที่ 6 — อาการ: กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า
- ไฟล์/บรรทัด: DashboardPage.jsx / 75-76
- สาเหตุ: มีการเรียก setRequests(resetRequests()) โดยไม่ได้ใส่ await ทำให้ State ได้รับ Object ของ Promise ไปแทน Array ข้อมูลจริง เมื่อ React นำไปเรนเดอร์ต่อจึงเกิด Error และหน้าจอพัง
- แก้อย่างไร: เพิ่ม await ด้านหน้าฟังก์ชัน และเก็บผลลัพธ์เป็นตัวแปร Array ก่อนส่งเข้า State
