# บันทึกการใช้งาน AI ในการพัฒนา (AI Usage Report) — Lab 11 (A4)

### 1. คำถามหรือปัญหาที่สอบถาม AI
* ปรึกษาและให้ AI ช่วยวิเคราะห์หาสาเหตุของข้อผิดพลาดเมื่อรันคำสั่ง build แล้วเกิดปัญหาเรื่อง package และ vite
* สอบถามแนวทางการแก้ปัญหาเมื่อพบบั๊ก alert แจ้งเตือนค่าสถานะไม่ถูกต้องตอนทดสอบเปลี่ยนสถานะคำร้อง

### 2. คำแนะนำและจุดที่ AI ช่วยชี้แนะ
* ชี้จุดผิดเรื่องการขาดแฟล็ก `--include=dev` ในสคริปต์ build ทำให้โหมด production ข้ามการติดตั้ง devDependencies ของ Vite
* ชี้จุดผิดของการส่งค่า payload ในปุ่มเปลี่ยนสถานะว่าส่งค่าไม่ตรงกับ validation ของ backend (`in-progress` / `completed`)
