## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) | RequestList.jsx : 9 | ใช้ฟังก์ชัน .map() วนลูปเรนเดอร์ <RequestCard/> แต่ไม่ได้ใส่ prop key ทำให้ React ระบุและติดตามแต่ละ Element ใน DOM ไม่ได้ | key={request.id} เข้าไปที่คอมโพเนนต์ <RequestCard/> |
| 2 | ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็นจริง | DashboardPage.jsx : 47 | เงื่อนไขการนับของ pending ใส่เป็น request.status === 'completed' ทำให้ค่าซ้ำกับช่องเสร็จสิ้น ตัวเลขจึงไม่ตรง | แก้เงื่อนไขจาก request.status === 'completed' เป็น request.status === 'pending' |
| 3 | กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่ | DashboardPage.jsx : 55 | ใช้เครื่องหมาย !== (ไม่เท่ากับ) ในการกรอง ทำให้ได้รายการที่สถานะไม่ตรงกับปุ่มที่กดเลือก | แก้เครื่องหมายจาก !== เป็น === เพื่อให้กรองเฉพาะสถานะที่ตรงกัน |
| 4 | เปลี่ยน URL `REQ-001` → `REQ-002` แล้วข้อมูลไม่เปลี่ยน | RequestDetailPage.jsx : 28 | Dependency array ของ useEffect ขาดตัวแปร requestId (มีแค่ [reloadKey]) ทำให้เมื่อเปลี่ยน URL ตัว React ไม่ยอมรัน Effect ดึงข้อมูลใหม่ | เพิ่ม requestId ลงไปใน Dependency Array เป็น [requestId, reloadKey] |
| 5 | กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย | DashboardPage.jsx : 65 | เรียก setRequests(requests) ซึ่งส่ง Array อ้างอิงเดิมเข้าไป React จึงมองว่า State ไม่เปลี่ยนและไม่ Re-render หน้าจอ | แก้เป็น setRequests(nextRequests) โดยส่ง Array ชุดใหม่ที่ได้จากการลบสำเร็จเข้าไปแทน |
| 6 | กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า | DashboardPage.jsx : 75-76 | ฟังก์ชัน resetRequests() เป็น Async ที่คืนค่าเป็น Promise แต่ไม่ได้ใส่ await ทำให้ State ได้รับ Object Promise ไปแทน Array ข้อมูลจริง | ใส่ await ด้านหน้า await resetRequests() และเก็บผลลัพธ์เป็น Array ก่อนส่งเข้า setRequests |
